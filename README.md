# 🏍️ MotoVerify

### Motorcycle Exhaust Compatibility & Documentation Portal

MotoVerify is a college mini project designed to help motorcycle enthusiasts explore motorcycle specifications, compatible aftermarket exhausts, and documentation status in one place.

## 🌐 Live Demo

**GitHub Pages:** https://prayaghariyani.github.io/MotoVerify/

## 📖 About the Project

Finding information about aftermarket motorcycle exhausts can be difficult because compatibility, specifications, and documentation are often scattered across different sources.

MotoVerify brings this information together through a simple and responsive web interface where users can search for a motorcycle and explore its available exhaust information.

## ✨ Features

* 🔍 **Motorcycle Search** – Quickly search for supported motorcycles.
* 🏍️ **Motorcycle Directory** – Browse motorcycles from multiple popular brands.
* ⚙️ **Specifications** – View engine capacity, power, torque, mileage, and related bike information.
* 🔧 **Exhaust Compatibility** – See aftermarket exhaust options associated with each motorcycle.
* 📄 **Documentation Status** – Check whether documentation is available for listed exhausts.
* 📱 **Responsive Interface** – Designed to work across desktop and mobile screen sizes.
* 📑 **Multi-page Website** – Includes Home, Motorcycles, About, and Contact pages.

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/prayaghariyani/MotoVerify.git
```

### 2. Open the project

```bash
cd MotoVerify
```

### 3. Run the website

This is a static website, so no backend or database setup is required.

You can open `index.html` directly in a browser or use **Live Server** in VS Code.
